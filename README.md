## About This Repository

This repository demonstrates core developer workflow fundamentals, including:
- **Linux System Administration:** Hardware inspection, binary number conversions, and command-line output logging.
- **Bash Shell Scripting:** Automated system reporting (`sysinfo.sh`) and compressed directory backups (`backup.sh`).
- **Git & GitHub Workflows:** Branch management, repository structuring, `.gitignore` rules, and incremental commits.
- **REST API Integration:** Fetching and parsing JSON payloads using `curl` and `jq`.
- **Web Portfolio & Career Planning:** Technical resume, semester-wise learning roadmap, and a live GitHub Pages site.
